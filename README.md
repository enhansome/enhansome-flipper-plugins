* [MMKV Viewer Plugin](https://github.com/ddyos/flipper-plugin-mmkv-viewer) ⭐ 28 | 🐛 2 | 🌐 Kotlin | 📅 2021-09-17 - View or edit the key-value inside the MMKV (WeChat key-value storage) file.
* [Thread Inspector Plugin](https://github.com/s1rius/android-thread-inspector) ⭐ 23 | 🐛 0 | 🌐 Kotlin | 📅 2021-12-16 - Show a table of threads and their stacks.
* [LifeCycle / BackStack Plugin](https://github.com/afaucogney/flipper-backstack) ⭐ 9 | 🐛 3 | 🌐 Kotlin | 📅 2021-10-24 - This Flipper plugin is an app introspection plugin focused on application life cycle.
